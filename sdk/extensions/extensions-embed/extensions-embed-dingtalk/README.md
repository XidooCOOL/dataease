# 钉钉嵌入集成插件

## 插件介绍

钉钉嵌入集成插件允许将 DataEase 仪表板无缝嵌入到钉钉工作台中，实现钉钉用户的单点登录和权限集成。

## 功能特性

- 支持钉钉扫码登录 DataEase
- 自动同步钉钉用户信息
- 支持基于钉钉部门的权限映射
- 提供标准嵌入链接
- 支持钉钉企业内部应用集成

## 使用说明

### 步骤一：配置钉钉应用

1. 登录钉钉开放平台 (open.dingtalk.com)
2. 创建企业内部应用
3. 获取 AppKey 和 AppSecret

### 步骤二：配置插件

在 DataEase 系统设置中配置钉钉嵌入插件：

| 参数 | 说明 |
| --- | --- |
| AppKey | 钉钉应用的 AppKey |
| AppSecret | 钉钉应用的 AppSecret |
| 启用 SSO | 是否启用钉钉单点登录 |

### 步骤三：创建嵌入链接

在仪表板设置中生成钉钉嵌入链接，用户可通过钉钉直接访问仪表板。

## 技术规格

- 钉钉 API 版本：v2
- 认证方式：OAuth2.0
- 单点登录：支持

## 注意事项

1. 需要企业管理员权限配置钉钉应用
2. 确保钉钉应用已开通相应权限
3. 嵌入的仪表板需要设置为"公开"或分配给对应用户
