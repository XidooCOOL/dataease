# 飞书数据源插件

## 插件介绍

飞书数据源插件允许 DataEase 连接飞书多维表格，读取多维表格数据进行可视化和分析。

## 功能特性

- 支持连接飞书多维表格
- 自动获取数据表和视图列表
- 支持只读权限和编辑权限
- 支持定时同步
- 兼容飞书和 Lark 国际版

## 使用说明

### 步骤一：配置飞书应用对接

在使用飞书数据源前，需先完成飞书应用的平台对接配置。进入【系统设置】>【平台对接】，确保飞书应用已正确配置并启用。

### 步骤二：授权飞书多维表格

确认飞书多维表格已授权对应的飞书应用访问相关数据。根据权限需求，选择以下授权方式：

| 授权方式 | 操作人 | 权限说明 |
| --- | --- | --- |
| 开通多维表格权限 | 企业管理员 | 仅提供只读权限 |
| 开通云文档权限 | 普通管理员 | 具备编辑权限 |

### 步骤三：获取 app_token

打开目标飞书多维表格，从浏览器地址栏 URL 中提取 `app_token`，位于 URL 最后一个 `/` 与 `?` 之间。

### 步骤四：配置飞书数据源

在数据源配置页面中填入 app_token，点击【获取数据表】和【获取视图】按钮，系统将自动加载该多维表格下的数据表和视图。

### 步骤五：设置定时同步

飞书数据源支持定时同步，操作方式与 API 数据源一致，可按需配置定时同步规则。

## 技术规格

- 飞书 API 版本：v6
- SDK：飞书官方 Java SDK
- 认证方式：OAuth2.0 / Tenant Access Token

## 注意事项

1. 飞书数据源依赖【平台对接】中的飞书应用配置
2. 使用前需确认飞书多维表格已对飞书应用完成授权
3. 插件涉及的 API 包括：查询记录、列出视图、列出数据表
